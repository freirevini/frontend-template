# AGENTS.md

Monorepo com três projetos independentes. Não há código nem comando na raiz: abra a pasta do projeto e leia o
`AGENTS.md` e a pasta `.rules/` dela antes da primeira ação.

- `langepage-angular/landing-analitica/` — painel Agenda Normativa em Angular 20.3 / Node 22 / CoreUI 5.5 (produto).
- `langepage-angular/frontend-template-angular/` — template base para painéis novos em Angular.
- `langepage-streamlit/` — réplica do painel em Streamlit (Python 3.11, Streamlit 1.40).

Mudança que atravessa projetos (contrato de dados, marca, regras comuns) é feita em cada um, seguindo as regras de cada
um. O mapa das pastas está no `README.md`.
