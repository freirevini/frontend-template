Botão Angular

O painel inclui vários componentes de botão predefinidos, cada um com seu próprio propósito semântico. Os botões mostram qual ação acontecerá quando o usuário clicar ou tocar neles. Os botões são usados para iniciar operações, tanto em segundo plano quanto em primeiro plano de uma experiência.

{{stateLabels[state]}} Botão Angular Componentes de botão

O componente <button> foi projetado para elementos <button> , <a> ou <input> (embora alguns navegadores possam aplicar uma renderização um pouco diferente).

Se você estiver usando o componente <button> como elementos <a> que disparam alguma funcionalidade, ex.: recolher conteúdo, esses links devem receber role="button" para comunicar adequadamente seu significado a tecnologias assistivas, como leitores de tela.

Link Botão Angular contorno

Adicione a propriedade booleana disabled a qualquer componente <button> para deixar os botões com aparência inativa. O botão desabilitado recebe pointer-events: none, impedindo que os estados de hover e ativo sejam acionados.

Botões desabilitados que usam o componente <a> se comportam de forma um pouco diferente:

Elementos <a> não suportam o atributo disabled, então é preciso adicionar a classe .disabled para deixar os botões com aparência inativa. Também é preciso adicionar ao componente de botão desabilitado o atributo aria-disabled="true" para informar o estado do componente às tecnologias assistivas.
