Junte conjuntos de grupos de botões em barras de ferramentas para componentes mais complexos. Use classes utilitárias conforme necessário para espaçar grupos, botões e muito mais.

Fique à vontade para combinar grupos de entrada com grupos de botões nas suas barras de ferramentas. Assim como no exemplo acima, você provavelmente precisará de alguns utilitários para espaçar os itens corretamente.

@ @ Grupo de botões Angular Tamanhos

Em vez de aplicar classes de tamanho a cada botão de um grupo, defina a propriedade size em todos os <c-button-group>, incluindo cada um deles ao aninhar vários grupos.
