Validação Estilos personalizados

Para mensagens de validação de formulário personalizadas, você precisará adicionar a propriedade booleana noValidate ao seu <CForm>. Isso desativa as dicas de feedback padrão do navegador, mas ainda dá acesso às APIs de validação de formulário em JavaScript. Tente enviar o formulário abaixo; nosso JavaScript interceptará o botão de envio e mostrará o feedback para você. Ao tentar enviar, você verá os estilos :invalid e :valid aplicados aos controles do formulário.

Os estilos de feedback personalizados aplicam cores, bordas, estilos de foco e ícones de fundo personalizados para comunicar melhor o feedback.

Validação Padrões do navegador

Não quer mensagens de feedback de validação personalizadas nem escrever JavaScript para mudar o comportamento do formulário? Tudo bem, você pode usar os padrões do navegador. Tente enviar o formulário abaixo. Dependendo do seu navegador e sistema operacional, você verá um estilo de feedback um pouco diferente.

Embora esses estilos de feedback não possam ser estilizados com CSS, você ainda pode personalizar o texto do feedback via JavaScript.

Validação Lado do servidor

Recomendamos usar validação no lado do cliente, mas, caso precise de validação no lado do servidor, você pode indicar campos inválidos e válidos com as propriedades booleanas invalid e valid.

Para campos inválidos, garanta que a mensagem de feedback/erro esteja associada ao campo correspondente usando aria-describedby (observando que esse atributo permite referenciar mais de um id, caso o campo já aponte para um texto de ajuda adicional).
