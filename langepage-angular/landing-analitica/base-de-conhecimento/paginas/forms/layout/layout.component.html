Layout Grid do formulário

Formulários mais complexos podem ser criados com nossas classes de grid. Use-as em layouts de formulário que exigem várias colunas, larguras variadas e opções adicionais de alinhamento.

Layout Espaçamentos

Ao adicionar classes modificadoras de espaçamento , você controla a largura do espaçamento tanto na direção inline quanto na direção de bloco.

Layouts mais complexos também podem ser criados com o sistema de grid.

Layout Formulário horizontal

Crie formulários horizontais com o grid adicionando a classe .row aos grupos do formulário e usando as classes .col-*-* para definir a largura dos rótulos e controles. Adicione também .col-form-label aos seus <label>s para que fiquem centralizados verticalmente com os controles de formulário associados.

Às vezes, pode ser necessário usar utilitários de margem ou espaçamento interno para obter o alinhamento perfeito. Por exemplo, removemos o padding-top do rótulo dos rádios empilhados para alinhar melhor a linha de base do texto.

Layout Tamanho dos rótulos em formulário horizontal

Use .col-form-label-sm ou .col-form-label-lg nos seus <label>s ou <legend>s para acompanhar corretamente o tamanho de .form-control-lg e .form-control-sm.

Layout Tamanho das colunas

Como mostrado nos exemplos anteriores, nosso sistema de grid permite colocar qualquer quantidade de <c-col>s dentro de um <c-row>. Eles dividem a largura disponível igualmente entre si. Você também pode escolher algumas colunas para ocupar mais ou menos espaço, enquanto os <c-col>s restantes dividem igualmente o resto, usando classes de coluna específicas como <c-col sm="7">.

Layout Tamanho automático

O exemplo abaixo usa um utilitário de flexbox para centralizar verticalmente o conteúdo e troca <c-col> por <c-col xs="auto"> para que as colunas ocupem apenas o espaço necessário. Em outras palavras, a coluna se dimensiona de acordo com o conteúdo.
