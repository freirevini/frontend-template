Controle de formulário Angular Tamanhos

Defina alturas usando a propriedade sizing, como sizing="lg" e sizing="sm".



Controle de formulário Angular Desabilitado

Adicione o atributo booleano disabled a um campo para deixá-lo com aparência acinzentada e remover os eventos de ponteiro.



Controle de formulário Angular Somente leitura

Adicione o atributo booleano readOnly a um campo para impedir a alteração do seu valor. Campos somente leitura aparecem mais claros (assim como os desabilitados), mas mantêm o cursor padrão.

Controle de formulário Angular Texto simples somente leitura

Se quiser que os elementos <input readonly> do seu formulário tenham estilo de texto simples, use a propriedade booleana plainText para remover o estilo padrão do campo e preservar a margem e o espaçamento corretos.
