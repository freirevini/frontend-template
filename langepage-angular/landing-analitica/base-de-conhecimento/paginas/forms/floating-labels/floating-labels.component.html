Rótulos flutuantes Angular

Envolva um par de elementos <cFormControl> e <label> em cFormControl para habilitar rótulos flutuantes em campos de texto do formulário. Um placeholder é obrigatório em cada <input>, pois nosso método de rótulos flutuantes somente com CSS usa o pseudoelemento :placeholder-shown. Observe também que o <cFormControl> deve vir primeiro para que possamos usar um seletor de irmãos (por exemplo, ~).

Quando já existe um value definido, os elementos <label> se ajustam automaticamente à posição flutuante.

Rótulos flutuantes Angular Áreas de texto

Por padrão, os <CFormTextarea>s terão a mesma altura que os <input>s.

Para definir uma altura personalizada no seu <CFormTextarea;>, não use o atributo rows. Em vez disso, defina um height explícito (seja inline ou via CSS personalizado).

Rótulos flutuantes Angular Seleções

Além do <input>, rótulos flutuantes só estão disponíveis em <cSelect>s. Eles funcionam da mesma forma, mas, ao contrário dos <input>s, sempre mostram o <label> no estado flutuante. Seleções com size e multiple não são suportadas.

Rótulos flutuantes Angular Layout

Ao trabalhar com o sistema de grid, coloque os elementos do formulário dentro de classes de coluna.
