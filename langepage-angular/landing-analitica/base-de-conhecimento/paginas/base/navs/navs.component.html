O componente base c-nav é construído com flexbox e oferece uma base sólida para criar todos os tipos de componentes de navegação. Ele inclui algumas sobrescritas de estilo (para trabalhar com listas), espaçamento interno nos links para áreas de clique maiores e estilização básica de [disabled]="true".

Ativo Link Link Desabilitado Navegação Angular Preencher e justificar

Faça o conteúdo do seu .nav ocupar toda a largura disponível com uma das duas classes modificadoras. Para preencher proporcionalmente todo o espaço disponível com seus elementos .nav-item, use layout="fill". Observe que todo o espaço horizontal é ocupado, mas nem todo item de navegação tem a mesma largura.

Para elementos de largura igual, use layout="justified". Todo o espaço horizontal será ocupado pelos links de navegação, mas, diferentemente do .nav-fill acima, todo item de navegação terá a mesma largura.
