Espaço reservado Angular

Crie espaços reservados com a diretiva cPlaceholder e uma diretiva de coluna de grade cCol (por exemplo, cCol="6") para definir a width. Eles podem substituir o texto dentro de um elemento ou ser adicionados como modificador a um componente existente.

Espaço reservado Angular Largura

Você pode alterar a width por meio de classes de coluna da grade, utilitários de largura ou estilos inline.

Espaço reservado Angular Cor

Por padrão, o cPlaceholder usa currentColor. Isso pode ser substituído por uma cor personalizada ou uma classe utilitária.

Espaço reservado Angular Tamanhos

O tamanho dos <CPlaceholder>s é baseado no estilo tipográfico do elemento pai. Personalize-os com a prop size: lg, sm ou xs.

Espaço reservado Angular Animação

Anime os espaços reservados com cPlaceholderAnimation="glow" ou cPlaceholderAnimation="wave" para transmitir melhor a percepção de algo sendo carregado ativamente.
