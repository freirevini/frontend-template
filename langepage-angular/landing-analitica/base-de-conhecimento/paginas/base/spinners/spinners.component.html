Indicador de carregamento Angular Borda

Use os indicadores de borda para sinalizar carregamento de forma leve.

O indicador de borda usa currentColor para sua border-color. Você pode usar qualquer um dos nossos utilitários de cor de texto no indicador padrão.

Indicador de carregamento Angular Crescente

Se você não gosta do indicador de borda, mude para o indicador crescente. Embora ele tecnicamente não gire, ele cresce repetidamente!

Mais uma vez, este indicador é construído com currentColor, então você pode facilmente alterar sua aparência. Aqui ele está em azul, junto com as variantes suportadas.

Indicador de carregamento Angular Tamanho

Adicione a propriedade size="sm" para criar um indicador menor que pode ser usado rapidamente dentro de outros componentes.

Indicador de carregamento Angular Botões

Use indicadores de carregamento dentro de botões para mostrar que uma ação está sendo processada ou em andamento. Você também pode remover o texto do elemento do indicador e usar o texto do botão conforme necessário.
