Cartão Angular

Os cartões são construídos com o mínimo possível de marcação e estilos, mas ainda assim oferecem bastante controle e personalização. Construídos com flexbox, eles oferecem alinhamento fácil e combinam bem com outros componentes do painel. Por padrão, os cartões não têm margens superior, esquerda e direita, então use os utilitários de espaçamento conforme necessário. Eles não têm largura fixa inicial, então ocupam toda a largura do elemento pai.

Abaixo está um exemplo de cartão básico com conteúdo misto e largura fixa. Os cartões não têm largura fixa inicial, então ocupam naturalmente toda a largura do elemento pai.

O bloco principal de um cartão é o <c-card-body>. Use-o sempre que precisar de uma seção com espaçamento interno dentro de um cartão.

Este é um texto dentro do corpo de um cartão. Cartão Angular Títulos, texto e links

Os títulos do cartão são gerenciados pela diretiva cCardTitle para <h*>. Da mesma forma, os links são anexados e agrupados lado a lado pela diretiva cCardLink para a tag <a>. Os subtítulos são tratados pela diretiva cCardSubtitle.

Coloque os itens cCardTitle e cCardSubtitle dentro de um <c-card-body>. O título e o subtítulo do cartão são organizados corretamente.

Os cartões não assumem nenhuma width específica de início, então terão 100% de largura, a menos que seja indicado o contrário. Você pode ajustar isso conforme necessário com CSS personalizado, classes de grade, mixins Sass de grade ou serviços.

Usando a marcação de grade

Usando a grade, coloque os cartões em colunas e linhas conforme necessário.

Usando utilitários

Use alguns dos utilitários de dimensionamento disponíveis para definir rapidamente a largura de um cartão.

Usando CSS personalizado

Use CSS personalizado nas suas folhas de estilo ou como estilos inline para definir uma largura.
