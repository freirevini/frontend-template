Progresso Angular Exemplo básico

Os componentes de progresso são construídos com dois elementos HTML, um pouco de CSS para definir a largura e alguns atributos. Não usamos o elemento HTML5 <progress> , garantindo que você possa empilhar barras de progresso, animá-las e colocar rótulos de texto sobre elas.

Progresso Angular Rótulos

Adicione rótulos às suas barras de progresso colocando texto dentro do <c-progress-bar>.

25% Progresso Angular Altura

Definimos apenas um valor de height no <c-progress>, então, se você alterar esse valor, o <c-progress-bar> interno será automaticamente redimensionado de acordo.

Progresso Angular Fundos

Use a prop color para alterar a aparência de barras de progresso individuais.

Progresso Angular Múltiplas barras

Inclua várias barras de progresso em um componente de progresso, se precisar.

15 30 20 Progresso Angular Listradas

Adicione variant="striped" a qualquer <c-progress-bar> para aplicar listras via gradiente CSS sobre a cor de fundo da barra de progresso.

Progresso Angular Listras animadas

O gradiente listrado também pode ser animado. Adicione a propriedade [animated]="true" ao <c-progress-bar> para animar as listras da direita para a esquerda via animações CSS3.
