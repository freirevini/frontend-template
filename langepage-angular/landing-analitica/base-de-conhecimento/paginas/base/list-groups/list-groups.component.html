Grupo de listas Angular Links e botões

Use elementos <a> ou <button> para criar itens de grupo de listas acionáveis, com estados de hover, desabilitado e ativo, adicionando component="a|button". Separamos essas pseudoclasses para garantir que grupos de listas formados por elementos não interativos (como <li> ou <div>) não ofereçam indicação de clique ou toque.

 Grupo de listas Angular Horizontal

Adicione layout="horizontal" para alterar o layout dos itens do grupo de listas de vertical para horizontal em todos os breakpoints. Como alternativa, escolha uma variante responsiva .layout="horizontal-{sm | md | lg | xl | xxl}" para tornar um grupo de listas horizontal a partir do min-width desse breakpoint. Atualmente, grupos de listas horizontais não podem ser combinados com grupos de listas flush.

 Grupo de listas Angular Classes contextuais

Use classes contextuais para estilizar itens de lista com fundo e cor que indicam estado.

  • Item simples de grupo de listas: {{ colorLabels[color] }}

As classes contextuais também funcionam com <a> ou <button>. Observe a adição dos estilos de hover aqui, que não aparecem no exemplo anterior. O estado active também é suportado; aplique-o para indicar uma seleção ativa em um item contextual do grupo de listas.
