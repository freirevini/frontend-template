Paginação Angular

Usamos um grande bloco de links conectados para a paginação, tornando os links difíceis de ignorar e facilmente escaláveis, tudo isso oferecendo grandes áreas de clique. A paginação é construída com elementos HTML de lista para que leitores de tela possam anunciar o número de links disponíveis. Use um elemento <nav> envolvendo-a para identificá-la como uma seção de navegação para leitores de tela e outras tecnologias assistivas.

Além disso, como as páginas provavelmente têm mais de uma seção de navegação desse tipo, é recomendável fornecer um aria-label descritivo para o <nav> que reflita seu propósito. Por exemplo, se o componente de paginação for usado para navegar entre um conjunto de resultados de pesquisa, um rótulo apropriado poderia ser aria-label="Search results pages".

« 1 2 1 » Paginação Angular Estados desabilitado e ativo

Os links da paginação são personalizáveis para diferentes situações. Use disabled para links que devem parecer não clicáveis e .active para indicar a página atual.

Embora a prop disabled use pointer-events: none para tentar desabilitar a funcionalidade de link dos <a>s, essa propriedade CSS ainda não é padronizada e não leva em conta a navegação por teclado. Por isso, sempre adicionamos tabindex="-1" em links desabilitados e usamos JavaScript personalizado para desabilitar totalmente sua funcionalidade.
